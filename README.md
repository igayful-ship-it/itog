# GitHub User Finder

**Автор:** Хуснутдинова Алина

## Описание

Десктопное приложение на Python для поиска пользователей GitHub через официальное API. Позволяет просматривать результаты поиска, добавлять пользователей в «избранное» и сохранять их локально в JSON-файл.

## Как использовать API

Приложение обращается к эндпоинту `https://api.github.com/search/users` с параметром `q` (строка поиска).  
Ответ содержит список пользователей, отображаемый в таблице.  
Для работы API не требуется токен, но он ограничен 60 запросами в час с одного IP.  
При желании можно добавить личный токен в заголовки (в коде это легко модифицировать).

## Примеры использования

1. **Поиск пользователя**  
   Введите «torvalds» в поле поиска → нажмите «Поиск». В таблице появится `torvalds` с ID и ссылкой на профиль.

2. **Добавление в избранное**  
   Выделите строку с найденным пользователем → нажмите «★ Добавить выбранного в избранное». Пользователь появится в нижнем списке.

3. **Удаление из избранного**  
   Выделите имя в списке избранных → нажмите «Удалить из избранного».

4. **Сохранение избранных**  
   Все избранные пользователи автоматически сохраняются в файл `favorites.json` (в папке с программой).

### Тесты (пример ручного тестирования)

| Действие                              | Ожидаемый результат                                |
|---------------------------------------|----------------------------------------------------|
| Поиск с пустым полем                  | Всплывающее предупреждение                         |
| Поиск несуществующего имени "xyzabc123" | Сообщение «Пользователи не найдены»               |
| Добавление одного пользователя в избранное | Он появляется в списке, JSON-файл обновляется  |
| Удаление из избранного                | Пользователь исчезает из списка, JSON обновляется  |
| Очистка всего избранного              | Запрос подтверждения, список очищается             |
